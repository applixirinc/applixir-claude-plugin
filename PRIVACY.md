# Privacy

**This plugin collects no data and makes no network calls of its own.**

- It's a set of instructions (a skill, two commands and reference documents) that Claude reads to edit code **in your own project**, on your machine or in your Claude session.
- It contains no scripts, hooks, MCP servers or telemetry, and it never contacts AppLixir or anyone else.
- It doesn't read, store or transmit your API key, callback secret or source code anywhere. The integration it writes reads your keys from your own configuration.

**After integration**, the AppLixir SDK that your game loads serves ads to your
players. That ad serving, and any data it processes, is governed by AppLixir's
privacy policy: https://www.applixir.com/privacy-policy/

Questions: support@applixir.com
